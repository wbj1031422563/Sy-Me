# 汽车展厅项目（主要在example/maxwell-car 目录下）

## 🚗 项目概述
搭建了**3D汽车展厅互动应用**，包含三大核心场景：
- 项目静态展厅
- 夜间道路行驶
- 功能展示

### ✨ 核心交互功能
- 车漆自定义 
- 汽车智驾行驶演示  
- 汽车粒子聚合动画  
- 汽车雷达扫描动画  
- 场景无缝过渡切换  
- 环境贴图动态光源模拟  
- 空气动力飞线动画  

## 💻 技术栈
**React** + **react-three/fiber** + **Three.js**

---

## 🔧 项目实现思路

### 1. 3D场景与用户交互设计
- 通过循环改变街道场景 Z 坐标，实现汽车无限行驶效果
- 支持多场景（展厅/道路/功能）的无缝过渡切换

### 2. 模型材质渲染与光照系统
- **道路渲染**：基于 PBR 材质实现雨天路面镜面反射效果
- **光源优化方案**：
  - 采用 Bloom 后期处理模拟路灯光源
  - 混合环境贴图替代动态光源，降低性能消耗
  - 动态光源贴图模拟真实环境反射

### 3. 🚀 系统性能优化
- **模型预处理**：
  - Blender 模型减面处理
  - DRACO 压缩模型体积
- **渲染优化**：
  - 动画帧回调中避免更新 React 状态
  - 采用Point 与 点材质高效加载动画粒子

### 4. 🎥 动画效果实现
| 动画类型             | 实现技术                                      |
|----------------------|---------------------------------------------|
| 汽车粒子聚合动画      | Shader + 包围盒检测 + BufferGeometry         |
| 环形律动粒子动画      | Shader + 噪声纹理驱动                       |
| 雷达扫描动画          | 动态几何体 + 扫描着色器                     |
| 空气动力飞线          | 曲线路径动画 + 粒子轨迹生成                 |

### 资产工作台

打开 `/tools/asset-workbench` 可以进行模型资产预处理和视觉替换：

- GLB：检查后可直接替换并预览；GLTF：只有贴图和 BIN 内嵌时才直接预览，否则提示转换为 GLB。
- 「模型资产管理」与「文件预处理与加载」分离：可新增、选择、隐藏和移除模型槽位，支持单模型、多模型和不同格式混合；文件会加载到当前选中的槽位。
- 「批量选择 GLB / GLTF」支持逐个预处理多个模型，成功文件自动创建新的模型槽位，外部依赖或不支持的文件会在批量队列中标记为需转换/失败。
- 「视觉方案中心」提供电影金色、白天田间、夜间作业、技术检查和性能优先五套组合方案，一键联动主题、背景、灯光、粒子、后期、色彩、镜头和材质；手动调整后自动回到自定义状态。
- 「视觉方案库」支持给当前整套配置命名保存、应用和删除，最多保留 20 套浏览器本地方案；只保存场景配置与资源清单，不复制模型和 HDR / EXR 文件。
- 视觉方案库支持导出 / 导入 JSON，导入时会过滤无效条目并合并到当前方案库，方便跨电脑迁移灯光、背景、粒子、镜头与渲染配置。
- 「镜头预设编辑器」支持新增、删除和编辑镜头名称、相机位置、观察目标与过渡时长；镜头会写入当前场景并随方案库保存。
- 「模型变换与落地」支持调整当前模型的位置、旋转、统一缩放和自动居中落地，适合多模型叠放、局部检查和快速构图。
- 「模型装配关系」支持给多个模型槽位设置父子关系；子模型会跟随父模型变换，移除父模型时子模型自动回到根部件。
- 装配点支持 `SOCKET_`、`MOUNT_`、`ANCHOR_` 节点约定；父子模型都提供挂载点时，可在工作台中选择两端并自动计算子模型对齐变换。
- 「装配方案预设」支持保存父子关系、挂载后的模型变换和部件显隐状态；方案保存在浏览器本地，可导入/导出 JSON，并按模型 ID、资产 ID 或名称匹配当前模型槽位。
- 「模型节点树」会读取 GLB 内部的节点父子结构，支持节点单独隐藏、隔离显示和恢复全部节点；节点可见性覆盖会随场景配置导出。
- 节点隐藏后会显示“显示”按钮和已隐藏数量，可逐个恢复，也可以用“恢复全部节点”一次性清除所有节点显隐覆盖。
- 节点树与三维画布已联动：点击节点名称或直接点击模型即可选中并高亮，按住 Shift 可进行基础多选，为后续批量变换和装配点对齐提供选择状态。
- 选中多个节点后会出现「选中节点批量变换」面板，可按局部坐标一次性叠加位移、旋转和缩放；变换写入场景配置，支持撤销、导出、导入和恢复选中节点的原始变换。
- FBX / OBJ / STL / PLY / DAE：完成格式识别和基础检查，建议在 Blender 中统一转换为 GLB。
- 支持按格式选择按钮、恢复示例模型、加载工作区割台、切换展厅/田间/夜间/技术主题。
- 支持选择内置 HDR / EXR 背景或上传自定义 HDR / EXR，并导出当前场景配置。
- 「快捷操作」支持一键播放全部动作、全部暂停、全部复位和显示/隐藏诊断轴；「导入场景配置」可以回读导出的 `.scene.json`，恢复模型、动作绑定、镜头、材质和渲染参数。
- 工作台会实时显示 FPS、Draw Call、三角面、几何体和纹理数量，并根据当前负载给出激进优化、平衡优化或无需优化建议；还可通过「导出当前画面」按钮下载当前渲染视图 PNG。
- 性能面板提供「应用推荐 / 激进优化 / 恢复高质量」按钮；快捷操作区还支持保存、恢复和清除浏览器本地视觉方案，适合保存灯光、背景、动作与渲染参数组合。
- 如果模型包含材质名称，工作台会显示「局部材质控制」，可按材质槽单独修改颜色、金属度和粗糙度，并随场景配置导出；点击「恢复原材质」即可撤销单个材质覆盖。
- 底部「材质」默认选中「原始材质」，可随时恢复模型自带的颜色和贴图。切换背景或主题时会保留当前材质，导出的场景也会记录该选择。
- 导入模型会自动居中并落地；模型管理面板会显示网格、顶点、三角面和包围盒尺寸。

割台原始模型 `text_model001.glb` 约 637 MiB，保留在本机，不纳入 Git。克隆项目后，可以点击「GLB」选择本机的同名模型，也可以将其放入 `public/model/` 后点击「工作区割台」。这两种方式都会识别割台的动作节点。

加载割台后，在「割台动作预览」里播放、暂停或复位；拨禾轮可切换「正向／反向」，转速（转/分）与动刀频率（次/秒）可独立调整，调到 0 会停住对应部件。底部「动刀近景」可查看刀片沿割幅方向往复。行程和转速为演示设定；导出的场景 JSON 会记录动作绑定、速度和转向。

如果 GLB / GLTF 自带 `animations`，工作台会额外显示「内置动画片段」面板，支持按名称选择片段、播放/暂停、复位和 0.1×–2× 调速；它与手动动作绑定互不覆盖。当前 `text_model001.glb` 的 JSON 区块没有内置动画片段，因此仍使用节点动作绑定来驱动拨禾轮和动刀。

动作绑定后还可以打开「显示诊断轴」：橙色轴线表示旋转部件，蓝色轴线表示平行往复部件，圆点表示旋转轴心或移动起点。诊断层默认关闭，只在检查轴向和轴心时启用。

### 动作能力体检与自定义绑定

导入 GLB / 内嵌依赖的 GLTF 后，工作台会快速读取 glTF JSON 元数据，检查：

- 内置动画片段和 rotation / translation 变换通道；
- 命中“拨禾轮、搅龙、滚筒、轮、动刀、筛”等命名规则的节点；
- 每个候选动作的类型、建议轴向、置信度和来源。

候选动作不会强行覆盖模型，可以逐项勾选或点击「采用自动建议」。如果模型没有统一命名，使用「手动定义动作」输入节点名，选择旋转/往复、轴向和速度即可生成可导出的 `motionTracks`。这套检查只读取 GLB 头部和 JSON 区块，不会为了初检复制数百 MB 的几何数据。

动作体检会把候选拆成“旋转候选”和“平行候选”：拨禾轮、搅龙、滚筒、轮等优先判断为旋转；动刀、刀片、筛、输送带等优先判断为平行往复。每个候选还会显示推荐轴向、轴向来源、识别置信度和轴心提示。旋转部件如果没有显式 `pivot`，建议在工作台中确认节点原点或通过 `extras.motion.pivot` 补充轴心；平行往复部件不需要轴心，只需要确认移动轴和行程。

如果你的导出流程能够写入 glTF 节点 extras，也可以让模型自描述动作：

```json
{
  "name": "拨禾轮",
  "extras": {
    "motion": {
      "kind": "rotation",
      "axis": [0, 1, 0],
      "direction": 1,
      "rate": 24,
      "maxRate": 90,
      "label": "拨禾轮转速"
    }
  }
}
```

`kind` 可用 `rotation` 或 `reciprocation`；往复动作还可以提供 `stroke`。元数据的优先级高于命名推断，适合后续从 Blender、CAD 或自研导出器自动生成稳定动作配置。

### 灯光、背景、渲染与粒子

工作台的「灯光 / 渲染 / 粒子」面板支持：

- 电影高光、柔和展示、性能优先三档质量预设；
- 曝光、环境光、主光/补光/轮廓光的颜色与强度；
- 背景纯色、Bloom、暗角、颗粒噪声和实时阴影；
- 关闭粒子、田间尘埃、收获金尘、技术光点四档粒子氛围，并可调粒子数量。
- 色彩分级：色调（°）、饱和度、亮度、对比度，以及 RGB Gain（增益）、RGB Lift（黑位）、RGB Gamma（曲线）；支持原始色彩、暖金色调、冷峻技术、夜间蓝调预设。

这些参数会随「导出当前场景配置」写入 `renderer`、`environment`、`effects`、`colorGrade` 和 `particles`，后续可以直接由接口或模型管理后台生成同样的视觉方案。高面数模型优先使用“性能优先”检查动作绑定，再按需要打开阴影、后期、色彩分级和粒子。

`colorGrade.hue` 使用角度，`saturation` / `brightness` / `contrast` 使用 -1 到 1，RGB 数组顺序固定为 `[R, G, B]`。Gain 默认 `[1, 1, 1]`，Lift 默认 `[0, 0, 0]`，Gamma 默认 `[1, 1, 1]`。
