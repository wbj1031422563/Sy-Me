启动项目：
1. 运行npm install
2. npm run dev

汽车展厅项目：
项目描述：搭建了一个3D汽车展厅互动应用，包含项目静态展厅，夜间道路行驶，功能展示三个场景。支持车漆自定义，汽车智驾行驶演示，汽车粒子聚合，汽车雷达，场景无缝过渡切换，环境贴图模拟动态光源，空气动力飞线等多种动画交互效果。
技术栈:React+react-three/fiber+Three.js
项目思路：
1.3D场景与用户交互设计与实现。通过循环改变街道场景z坐标，实现汽车无限行驶效果；
2.模型材质渲染处理与场景光照搭建。基于 PBR材质渲染道路，实现了雨天路面的与镜面反射地面的效果；基于Bloom模拟路灯光源，解决过多光源带来性能问题；基于混合环境贴图模拟光源，解决了动态光源的高性能消耗问题；
3.系统性能优化处理。通过Blender对模型进行减面处理；采用DRACO压缩模型；避免在动画帧回调中更新React响应式变量；采用MeshInstacne加载动画粒子；
4.各种动画效果的实现；基于Shader+包围盒+BufferGeometry，组合粒子显隐位移动画和模型显示动画，实现动画汽车粒子聚合效果；基于shader+噪声纹理，实现了环形律动粒子动画；同时也实现了车辆行驶的雷达扫描动画效果。
